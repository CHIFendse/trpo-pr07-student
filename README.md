# Практическая работа №07: PHP MVC интернет-магазин. Каркас приложения, маршрутизация и контроллеры

## Описание проекта
Каркас интернет-магазина, построенный на базе архитектурного паттерна MVC (Model-View-Controller) без сторонних фреймворков. В проекте реализована единая точка входа (`Single Point of Entry`), табличный маршрутизатор (`Router`), базовые контроллеры страниц и двухуровневая система представлений (макет + контентный шаблон).
